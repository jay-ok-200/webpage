# DAEGU, YOUR WAY — 大邱双语旅游展示网站
# DAEGU, YOUR WAY — 대구 중한 이중언어 관광 소개 웹사이트

## 한국어 안내

이 프로젝트는 대한민국 대구광역시의 관광 자원을 소개하는 순수 정적 반응형 웹사이트입니다. PC, 태블릿, 스마트폰에서 이용할 수 있으며, 모든 페이지 문구는 중국어와 한국어를 함께 제공합니다.

### 프로젝트 파일

- `index.html`：웹페이지 구조 및 중국어·한국어 콘텐츠
- `styles.css`：웹사이트 디자인, 반응형 레이아웃 및 모바일 화면 최적화
- `script.js`：모바일 내비게이션 메뉴, 관광지 카테고리 필터 및 즐겨찾기 기능
- `README.md`：프로젝트 설명 및 사용 안내(중국어·한국어)

### 로컬에서 미리보기

**방법 1: 파일 직접 열기**

프로젝트 압축을 푼 다음 `index.html` 파일을 더블 클릭하면 브라우저에서 웹사이트를 확인할 수 있습니다.

**방법 2: 로컬 서버 실행**

프로젝트 폴더에서 다음 명령어를 실행하세요.

```bash
python3 -m http.server 8000
```

그런 다음 브라우저에서 아래 주소로 접속하세요.

```text
http://localhost:8000
```

### 웹사이트 배포

이 프로젝트는 별도의 패키지 설치나 빌드 과정이 필요하지 않습니다. 백엔드와 데이터베이스도 사용하지 않습니다. 프로젝트 폴더 전체를 다음과 같은 정적 웹 호스팅 서비스에 업로드하면 됩니다.

- GitHub Pages
- Netlify
- Vercel Static
- 자체 웹 서버 또는 웹 호스팅 서비스

`index.html`, `styles.css`, `script.js` 파일이 같은 폴더에 있도록 유지해 주세요.

### 주요 기능

- 대구 관광 테마 메인 페이지
- 대구 주요 관광 명소 소개
- 자연, 문화, 미식 카테고리별 관광지 필터
- 관광지 즐겨찾기 버튼
- 테마별 추천 여행 코스 3가지 및 Google Maps 길찾기 링크
- 대구 지역 음식 소개
- 교통, 날씨 및 관광지 운영 정보 안내
- PC, 태블릿, 스마트폰에 대응하는 반응형 레이아웃
- 웹사이트 전체 중국어·한국어 이중언어 문구

### 참고 및 유의 사항

1. 웹사이트 이미지는 Unsplash 이미지 서비스를 통해 불러오며, 글꼴은 Google Fonts를 사용합니다. 이미지와 글꼴을 정상적으로 표시하려면 인터넷 연결이 필요합니다.
2. 지도 링크를 누르면 Google Maps의 장소 검색 또는 경로 안내 페이지가 열립니다.
3. 관광지 운영 시간, 입장료, 야시장 운영 및 행사 일정은 날짜, 날씨 또는 주최 측 사정에 따라 변경될 수 있습니다. 방문 전 각 관광지와 공식 기관의 최신 공지를 확인해 주세요.
4. 본 웹사이트는 독립적으로 제작한 관광 소개용 콘셉트 사이트이며, 대구광역시 또는 공식 관광 기관의 공식 웹사이트가 아닙니다.

## 中文说明

这是一个用于展示韩国大邱市旅游资源的纯静态响应式网站。网站面向电脑、平板和手机浏览，所有页面文案均同时提供中文和韩文。

### 项目文件

- `index.html`：网站页面结构及中韩双语内容
- `styles.css`：网站视觉样式、响应式布局及移动端适配
- `script.js`：移动端导航菜单、景点分类筛选和收藏交互
- `README.md`：项目说明与使用指南（中韩双语）

### 本地预览

**方法一：直接打开**

解压项目后，双击 `index.html`，即可使用浏览器预览网站。

**方法二：启动本地服务器**

在项目目录中运行：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问：

```text
http://localhost:8000
```

### 网站部署

本项目无需安装依赖、无需构建，也不需要后端或数据库。将整个项目文件夹上传到任意静态网站托管服务即可，例如：

- GitHub Pages
- Netlify
- Vercel Static
- 自有 Web 服务器或虚拟主机

请确保 `index.html`、`styles.css` 和 `script.js` 保持在同一目录中。

### 网站功能

- 大邱城市旅游主题首页
- 大邱主要景点介绍
- 按自然、文化、美食分类筛选景点
- 景点收藏按钮
- 三条主题旅游路线及 Google Maps 导航链接
- 大邱特色美食介绍
- 交通、天气和景点开放信息提示
- PC、平板及手机响应式布局
- 全站中文与韩文双语文案

### 注意事项

1. 网站图片通过 Unsplash 图片服务加载，字体使用 Google Fonts，因此图片和字体需要联网才能正常显示。
2. 地图链接会打开 Google Maps 的地点搜索或路线页面。
3. 景点开放时间、门票、夜市运营及活动安排可能随日期、天气或主办方安排变化。出行前请以各景点及官方机构的最新公告为准。
4. 本网站是独立制作的旅游展示概念网站，并非大邱市政府或官方旅游机构的官方网站。
